# PC-1350 Emulator for MacOS

SHARP のポケットコンピュータ PC-1350 の、macOS 用エミュレータです。

> SHARP とは関係のない、個人のプロジェクトです。

## 動作環境

- macOS 11 以降
- Apple Silicon / Intel の両方に対応（ユニバーサル）

## 準備

### ROM

ROM は付属していません。お手持ちの実機から吸い出して、ご用意ください（吸い出し方は、「PC-1350 ROM 吸い出し」などで検索すると見つかります）。

| ROM | ファイル名 | 大きさ |
|---|---|---|
| CPU の内蔵 ROM | `cpu.rom`（または `cpu-1350.rom`） | 8KB |
| BASIC の ROM | `basic.rom`（または `bas-1350.rom`） | 32KB |

起動したディレクトリか、`pc1350` と同じディレクトリに置いてください。

### 状態のファイル

電源を切ったときのメモリとレジスタの状態は、起動したディレクトリに保存されます。

| RAM カード | ファイル |
|---|---|
| 16KB（既定） | `mem-16.bin` / `registers-16.json` |
| 8KB | `mem-8.bin` / `registers-8.json` |
| なし | `mem.bin` / `registers.json` |

## 起動と終了

ターミナルから起動します。

```sh
./pc1350
```

- **終了**: ウインドウを選んだ状態で ⌘Q を押すか、ウインドウを閉じます。そのときの状態を保存して終了し、次に起動すると、続きから始まります。
- ターミナルで Control+C を押して止めると、状態は**保存されません**。

ROM や状態のファイルの場所、RAM カードは、オプションや環境変数で変えられます。詳しくは `./pc1350 --help` を見てください。

## キー操作

| PC-1350 | Mac |
|---|---|
| 文字・数字・記号 | そのまま入力（SHIFT 側の記号も、そのまま打てば SHIFT を押してから入力されます） |
| ENTER・矢印・スペース | Enter・矢印・Space |
| CLS | Esc |
| MODE | Tab |
| BRK（ON） | F13 または ⌘. |
| INS | F2 |
| DEL | Delete（fn+Backspace） |
| BS（← と DEL） | Backspace |
| SHIFT | Shift（単独で押して離す） |
| DEF | Option |
| SML | Control |

### 貼り付け

⌘V で、テキストを貼り付けて入力できます。貼り付けの間は、速さの制限なしで動くので、長いプログラムもすぐに入ります。

## 速さ

CPU の速さは実機に合わせてありますが、Machine メニューの Speed で、0.1 倍から 1000 倍・無制限まで変えられます。

- 1 倍以外のときは、音は出ません（CSAVE・CLOAD も 1 倍で使ってください）。
- 入力待ちの間は、実際の時間で進みます。

## テープ（CSAVE / CLOAD）

Mac の音声の入出力を、テープレコーダーの代わりに使えます。Audio メニューで、デバイスを選びます。

- **CLOAD Input**: CLOAD で読む音の入力。実機で録音した音を再生して読み込めます。BlackHole などの仮想オーディオデバイスを使えば、音声プレーヤーのソフトから直接入力できます。
- **CSAVE / Sound Output**: CSAVE の音（BEEP なども同じ）の出力先。
- CLOAD Input を選ぶと、マイクの使用の許可を求められ、使っている間はメニューバーにマイクのアイコンが出ます。入力の音は CLOAD の読み取りにだけ使い、保存や送信はしません。

## 画面

Display メニューで、表示方式と大きさを選べます。

- **LCD** と **B/W**（白黒。Light・Dark・システムに合わせる）を選べ、それぞれで設定したコントラストを覚えます。
- 50%・100%・200% のほか、ウインドウの縁をドラッグして自由に大きさを変えたり、フルスクリーンにしたりできます。
- File → Export Screen Image… で、画面を画像に書き出せます。
